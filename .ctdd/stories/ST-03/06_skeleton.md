## Decisions taken here (for Quentin)

1. **`Value` name clash — resolved.** Quentin chose (c) on 2026-11-04: ST-01's `write::Value` is renamed `FieldValue` (foundation amendment); the new `Value` is re-exported at the crate root with `Output`, `encode`, `render`.
2. **Booleans and lists are declared `required: true`.** RG-ST03-4.6 refuses "optional boolean / optional list" and RG-ST03-4.4 wants them always present, so `required: false` on them is refused. On the command line they stay optional (absent = `false` / `[]`). In the JSON Schema form they are listed in `required`.
3. **JSON Schema form fixed by goldens**: objects always carry `additionalProperties:false`, `properties`, `required` (sorted by name, possibly empty), `type`. Each property carries `description`. Enum values stay in declaration order. List `items` have no description.
4. **`ActionError` fields private**, so `Success` cannot be represented (RG-ST03-3.4). Constructors, `with_data` and accessors are written in full (plain field init, no logic), so T-3/T-4/T-5 do not wait on T-2.
5. **Test descriptors written by the Skeleton** (`wiring/test.rs`, data only). They are the contract the acceptance tests and the core mirror (`echo_input` in `core/tests/catalog.rs`) depend on. Echo's list property is `tag` (`--tag`, key `tag`), following matrix US-4 row 3. Matrix US-2 row 3 says `tags`. `test.write` input `key`, optional `fail` (`refusal|tool-error|panic`), output `{key}`. `test.read` outputs `{keys: [..]}` in write order.
6. **Foundation actions**: the test module registers two wirings, `test` and `arbitre` (for `arbitre.test-foundation`), because the first segment must equal the module id. `modules.rs` gets a private `shipped()` (empty) plus `all()` = shipped + `test::wirings()`, and `catalog(&[Wiring])`, so F-7's "without test-actions" test is `catalog(&shipped())`. Adding a module = its `mod` line + one line in `shipped()` (P-5 unchanged in spirit).
7. **RG-ST03-4.6 "module id `arbitre` outside the foundation"** has no test: `Catalog::build` cannot tell the foundation from another wiring with id `arbitre`. To settle at ST-04 (`Module` can carry it).
8. **Platform rule for `location`**: `macos` → `Library/Application Support`; `windows` → `no_default_store`; any other OS → the XDG rule. An empty `HOME` counts as missing.
9. Smaller choices: string lengths count characters; duplicate property names are refused; non-object input/output schemas are refused. The shared test helper is `tests/support/mod.rs` (a `tests/support.rs` would become its own test target). The read-only-directory test skips itself when it runs as root.
